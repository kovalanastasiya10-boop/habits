АТОМНЫЕ ПРИВЫЧКИ — приложение для Android (бесплатно)

ВАРИАНТ 1. Установить как приложение (PWA) — 10 минут
1. Зарегистрируйтесь на github.com (бесплатно).
2. New repository → имя, например, habits → Public → Create.
3. "uploading an existing file" → перетащите ВСЕ файлы из этого архива → Commit.
4. Settings → Pages → Source: Deploy from a branch → main / (root) → Save.
5. Через 1–2 минуты сайт будет по адресу https://ВАШ_ЛОГИН.github.io/habits/
6. Откройте его в Chrome на телефоне → меню ⋮ → «Установить приложение»
   (или «Добавить на главный экран»). Иконка появится среди приложений,
   работает без интернета.

ВАРИАНТ 2. Получить настоящий APK-файл
1. Сделайте шаги 1–5 из варианта 1.
2. Откройте pwabuilder.com, вставьте адрес сайта → Start.
3. Package for stores → Android → Generate package → скачайте архив.
4. Внутри будет .apk — перекиньте на телефон и установите
   (разрешите установку из неизвестных источников).
   Этот же пакет (.aab) можно загрузить в Google Play или RuStore.

ДАННЫЕ
Привычки хранятся только на телефоне. Раздел «Система» → «Скопировать данные»
даёт код резервной копии — сохраните его в заметках.
